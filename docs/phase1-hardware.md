## 1. 一期交付到底是什么

一台免焊接、完整装配、可重复烧录恢复的 USB-C 有线桌面设备，配套 Windows 软件和 VS Code 扩展。包含 20 键矩阵、独立 2U 大键、方屏、带按压旋钮、五向开关；真实双会话状态上屏，旋钮选择、大键准确返回选中会话。

- 你负责产品决策、软件联调和收货验收；不要求你焊接、画 PCB 或处理裸 FPC。
- 硬件合作方负责器件确认、电路、载板、接线、结构、装配及硬件问题返修。固件可由软件侧实现，但合作方必须承担首次点亮和刷机协作；报价中明确固件由谁写。
- 先用开发板＋屏＋按钮验证，再做完整载板和外壳。模块样机不能算一期完成。
- 一期不装电池，不设计充电、不做 BLE／2.4G／接收器，不做 RGB、触摸、板载麦克风或动画桌宠。保留原项目的三模首发目标，另经 S2 验证。
- 一期采用 1.54 英寸屏允许验证闭环；不宣称已达到 2.1 英寸效果图。改成目标大屏必须重做显示、电源、结构验收。
- 允许使用成品 Pico 2 模块插接载板，不强制第一版直接设计 RP2350 裸芯片主板；这样降低首次打板风险。

## 4. 引脚与固件接口：开板前必须完成

概念预算按 Pico 2 的 26 个外引 GPIO 计算，以下只证明资源大致可安排，不是接线图：

| 功能 | GPIO 预算 | 说明 |
| --- | --- | --- |
| 5×4 按键矩阵 | 9 | 每键二极管，定义行列扫描方向和二极管方向 |
| 独立大键 | 1 | 可直接输入，共地与上拉由电路确认 |
| 编码器 A/B 与按压 | 3 | 输入和去抖；长线噪声由实物测试 |
| 五向开关 | 5 | 五路开关；多方向与中心仲裁写进固件 |
| LCD SCK、MOSI、CS、DC、RST、BL 控制 | 6 | 默认单向写屏；BL 只是驱动电路控制，不直接承担背光电流 |
| 合计 | 24 | 留 2 个 GPIO；调试口、模组特殊要求仍须实查 |

合作方交付接线表，至少含：信号名、开发板物理脚号、GPIO 编号、方向、电平、上拉／下拉、电源来源、连接器脚号、线色和备注。固件使用同一表生成或人工核对板级配置。屏幕具体版本若增加 MISO／触摸等引脚，重新预算，不能随意共用已有引脚。

验证矩阵多键组合无鬼键，按下与释放数量对应；明确 USB 报告支持的同时按键数，不把“每键能单独识别”称为无限键无冲。旋钮与屏刷并发时不能遗漏输入。一期避免额外扩展芯片，若资源不足先复核接法和范围。

## 5. USB-C 与供电

1. 台架阶段允许 Pico 2 原有 Micro-USB。整机交付必须为牢固的 USB-C 外部入口，不靠悬空转接头；内部可用经过验证并固定的短数据连接到 Pico，或经工程师审查的载板连接。原板另一个供电入口不能形成双路反灌。
2. USB-C 作为受电设备，CC1／CC2、D+／D-、屏蔽与 ESD 按 USB 参考设计实现；由硬件方核对，不让用户照概念文档焊接。测试 C 插头两个方向、A-to-C 和 C-to-C 数据枚举。
3. 仅 USB 单电源输入。列 5V、3.3V 每路额定与峰值预算；检查 Pico 板上稳压余量、LCD 模组实际输入要求及背光电流。GPIO 不可承受 5V 逻辑，不可直接驱动未知电流背光。
4. 电流预算覆盖启动、满背光、连续刷新和全部控件操作；描述符的功耗声明、枚举前状态及主机可提供电流要与实际一致。预算不够时增加合适稳压／背光驱动或限亮，不能以“电脑口供得动”通过。
5. 收集 USB 总线休眠、主机睡眠／唤醒时的电流与状态；一期不依赖远程唤醒，休眠时停止正常刷新并按设计降低功耗，恢复后重新同步，不重放动作。
6. 合作方首通电先检查短路、极性和焊接，用限流电源或合适保护测试方式点亮；发货后不要求用户自己排查裸板短路。
7. USB 设备使用稳定序列号和明确的厂商通道标识，上位机不能误打开其他键盘。开发用 VID/PID 的使用条件写入记录；不得擅自复用他人商用标识，销售前另行解决合法分配。

## 6. 屏幕与结构冻结

- 逐项记录可视区、模块外形、安装孔、接口高度、控制器、像素格式、偏移、旋转方向、逻辑电平、供电、背光和实际 SPI 时钟。规格书允许范围不等于已通过当前接线长度的范围。
- 使用行缓冲或小区域缓冲，静态卡片本地绘制。固件提交 RAM／Flash 占用及压力测试；按键扫描不等待整屏阻塞传输。中文固定字形和短会话代号需清晰可区分。
- 显示切换过程中禁止执行未完全呈现的新映射；先进入不可操作更新态，显示完整后原子发布可交互快照，再发 `STATE_APPLIED`。按键恰好发生在更新中必须拒绝或返回旧的仍可见完整快照，不能看到 A 却跳 B。
- 结构先做屏幕、轴座、定位板、卫星轴钢丝、旋钮、五向开关、USB 及 Pico 的三维堆叠；Pico 排针和内部 USB 插头也计入高度。不要沿用效果图的 32.5 mm 作为承诺。
- 大键左右端按压、卫星轴回弹、屏幕视角与反光、摇杆帽间隙、USB 插拔受力及螺丝长度由实物复核。屏排线／线束避开钢丝和活动机构并固定。
- BOOTSEL、复位和 SWD 恢复入口须有可操作方案。装壳后能通过按钮／明确的开盖步骤恢复；首次烧录、升级失败恢复均需视频或逐步图文。
